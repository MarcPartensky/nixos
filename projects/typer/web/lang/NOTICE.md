Word lists in this directory
============================

english200, english1000, french200, french1000, rust, python, javascript, sql
come from ttyper, the terminal typing tester by Max Niederman, MIT licensed:

  https://github.com/max-niederman/ttyper/tree/main/resources/runtime/language

They are copied verbatim (one token per line, newline separated) so the web
version drills exactly the same vocabulary as `ttyper -l <language>` in a
terminal. Nothing here is generated or edited by hand.

The two "ascii" variants in the language menu are not files: the app filters
the French lists on the fly to drop tokens that require a dead key or AltGr
chord on a US physical keyboard.
