    Version terminal

    Cette page est la version web. Le client terminal se connecte aux mêmes salles. 

    typer-race                          # picks a random room
typer-race --room ABCD              # joins room ABCD
typer-race --room ABCD --name marc
typer-race --url ws://127.0.0.1:9146/ws

    Pour un exercice solo hors ligne, ttyper reste installé :

    ttyper                       # 50 English words
ttyper -w 25                 # 25 words
ttyper -t 30                 # 30 seconds
ttyper -l french200          # French list
